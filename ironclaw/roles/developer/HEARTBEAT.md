# Heartbeat Checklist

## Daily
- [ ] Check for open PRs awaiting review
- [ ] Check for failing CI/CD pipelines in active repos
- [ ] Surface any TODO/FIXME added in last 24h

## System
- [ ] Check disk usage — alert if above 85%
- [ ] Check if inference services are running (LiteLLM, IronClaw)

## Weekly
- [ ] Summarize merged PRs and closed issues this week
- [ ] Check for dependency updates with security advisories
- [ ] Check for outdated packages in active projects
