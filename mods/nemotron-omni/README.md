# mod: nemotron-omni

Pre-launch setup for Nemotron-3-Nano-Omni.

## What it does
1. Installs `vllm[audio]` — required for audio and video input support
2. Downloads `nano_v3_reasoning_parser.py` — reasoning parser for nemotron_v3

## Required by
- recipes/nemotron-3-nano-omni-nvfp4.yaml
